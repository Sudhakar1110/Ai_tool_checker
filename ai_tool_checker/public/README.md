# Public README

The **public** folder contains static assets that are served to the browser.

- `css/ai_tool_checker.css` – Styles for the dashboard and portal (glassmorphism, micro‑animations).
- `js/ai_tool_checker.js` – Client‑side script that handles AJAX calls, UI interactions, and Frappe‑compatible event handling.

These assets are built and copied to `sites/assets/ai_tool_checker/` during `bench build`.
