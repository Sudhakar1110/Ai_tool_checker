# Doctype README

This folder contains all DocType definitions for the **AI Tool Checker** app.

- **ai_tool** – Master record for each AI tool.
- **ai_tool_category** – Categories such as NLP, Vision, Code, etc.
- **ai_tool_industry** – Industry mappings.
- **ai_tool_check_log** – Transactional log of tool checks.
- **ai_tool_review** – User reviews and ratings.

Each DocType has a JSON schema and a corresponding Python controller file.
